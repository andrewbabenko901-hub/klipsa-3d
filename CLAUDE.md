# klipsa-3d — инструкция для Claude Code

Это рабочая записка для того, кто правит код. Что приложение делает и почему —
в `README.md`, он подробный и пользовательский. Здесь только то, что нужно,
чтобы не сломать проект: правила, карта модулей, инварианты и как проверять.

---

## 1. Что это за проект

Веб-приложение целиком в браузере: фотография пластиковой автомобильной клипсы
на входе — обмер силуэта, разбор на примитивы, параметрическая 3D-модель,
чертёж, STL и рецепт из элементов конструктора **ClipGen** на выходе.

Сервера нет. Сборки нет. Открывается как статика с GitHub Pages:
`https://andrewbabenko901-hub.github.io/klipsa-3d/`

Смысл всей затеи — **форма берётся с фотографии как силуэт**, а модель
собирается из своих параметрических элементов. Это единственная причина, по
которой у проекта нет лицензионных вопросов.

## 2. Правила, которые не обсуждаются

1. **Никаких чужих STL и чужих 3D-моделей.** Ни в репозиторий, ни в расчёт.
   Форма приходит только с фотографии, как силуэт.
2. **Никаких булевых вычитаний.** Ни здесь, ни в ClipGen. Отверстия и пазы
   делаются формой элемента, а не вычитанием тел.
3. **Ключи не попадают ни в код, ни в репозиторий.** Только `localStorage` в
   браузере или `.env` на сервере. В исходниках не должно быть ни одного
   `nvapi-`, `sk-`, `AIza`.
4. **`js/elementy.js` — чужой файл.** Это выгрузка конструктора ClipGen. Его не
   правим: если элементу не хватает параметра, масштабирование и обходные пути
   делаются в сборке (`js/sborka.js`), а нехватку записываем в раздел 8.
5. **Всё, что показано пользователю, должно быть посчитано.** Никаких
   «примерно так выглядит»: если цифра выведена, она получена из снимка или из
   каталога, и в интерфейсе видно, откуда.

## 3. Карта модулей

Порядок примерно соответствует конвейеру.

| файл | за что отвечает |
|---|---|
| `js/algoritmy.js` | обработка изображений без библиотек: маски (заливка, Оцу, насыщенность, градиент), морфология, компоненты, PCA, контуры, RDP, профили, нарезка на тела динамическим программированием |
| `js/obmer.js` | обмер снимка: 40 полос, дыры, материал, светотень; `ROLI`, сопоставление двух видов, согласие высот, отрисовка масок и листа разбора |
| `js/kruglost.js` | сечение по светотени: купол против плоского ската, парабола методом наименьших квадратов, блик |
| `js/narezka.js` | нарезка готового листа с видами на отдельные картинки (см. раздел 6) |
| `js/objyom.js` | image→3D: GLB → меш → PCA → крен по минимальному описанному прямоугольнику → силуэты; **меш после этого выбрасывается** |
| `js/siluet.js` | силуэт геометрии, сравнение силуэтов (IoU + наложение), подгонка размеров покоординатным спуском |
| `js/nejro.js` | поставщики: gemini, openai, anthropic, openrouter, huggingface, together, nvidia, свой адрес; списки моделей, сжатие фото, рисование картинок |
| `js/shema.js` | промпты: разбор, лист, эталонный вид |
| `js/konsensus.js` | сведение голосов источников |
| `js/sborka.js` | масштаб в миллиметры, замеры каждого тела, выбор элемента конструктора, сжатие по Z |
| `js/elementy.js` | **не трогать** — элементы ClipGen |
| `js/geom.js`, `js/vidy.js`, `js/stl.js` | сложение геометрии, чертёж и лист, экспорт STL |
| `js/main.js` | состояние `S`, интерфейс, конвейер, обработчики |

## 4. Инварианты, которые легко нарушить

**Версия в импорт-карте.** Модули кэшируются браузером намертво. В
`index.html` есть импорт-карта, где у каждого модуля свой `?v=NN`, и бейдж
версии в шапке. **После любой правки js подними число везде разом** — иначе
пользователь получит новый HTML со старыми модулями, и это выглядит как
«функция не работает», а не как кэш. Проверять так:

```bash
grep -c 'v=17' index.html   # должно совпадать с числом модулей + main.js
```

**Снимок старше рисунка.** Где роли совпадают, размеры берутся с фотографии, а
не с нарисованного вида. Помощник `svoiFoto()` в `main.js` возвращает только
настоящие снимки — на разбор нейронке и на лист уходят они.

**Нарисованное проверяется силуэтом.** Любой вид, пришедший не с камеры
(нейронка, объём, лист), сверяется с настоящим снимком через `SIL.sravnit`.
Ниже порога — отбрасывается целиком, и в интерфейс пишется процент.

**`window.__S = S`** оставлен намеренно: в консоли браузера видно всё состояние.
Это основной способ отладки, не убирать.

**Имена — латиницей по-русски** (`obmerit`, `narezatList`, `szhatie`). Не
смешивать в одном идентификаторе кириллицу и латиницу — такое уже ломало сборку.

## 5. Состояние `S` (в `js/main.js`)

```
foto[]        загруженные картинки: {url, img, b64, mime, rol, izLista?}
izmery[]      обмер по каждому виду: {rol, nomer, izmer, izLista?, izNejronki?}
izmer         главный обмер (вид спереди)

tela[]        нарезка на тела

```

## 6. Лист от нейронки (`js/narezka.js`)

Картиночные модели Google по API требуют биллинга, а на своей странице рисуют
бесплатно. Поэтому лист по шаблону рисуется руками и отдаётся файлом.

Панели ищутся **по просветам, а не по рамкам**: столбцы и строки, где чернил
меньше 0.4 % длины, считаются пустыми; пустая полоса шире 1.2 % стороны —
граница. Подписи отсеиваются по площади (меньше 12 % от медианной панели).
Изометрия угадывается по вертикальной симметрии (порог 0.80) и помечается
«не брать». Роли правятся руками в интерфейсе.

## 7. Реальность внешних сервисов (проверено живыми запросами)

| сервис | из браузера | заметка |
|---|---|---|
| OpenRouter | **да** | CORS открыт. Есть бесплатные зрячие модели и картиночные модели Google |
| Hugging Face router | **да** | `router.huggingface.co/v1` |
| Together AI | **да** | модели с суффиксом Free |
| Google Gemini | да, но | разбор бесплатен; **все** картиночные модели имеют Free Tier «недоступен» → 429 всегда |
| NVIDIA NIM | **нет** | CORS закрыт, нужен прокси. Разбор работает, ключ обязан быть `nvapi-`, а не персональный NGC |
| NVIDIA картинки | **нет** | `ai.api.nvidia.com/v1/genai/...` на бесплатных кредитах не отвечает вовсе (проверено, 5 минут таймаута) |
| Cloudflare Workers AI | **нет** | CORS закрыт, но свой Worker решает разом и прокси, и модели |

Рисование по умолчанию — OpenRouter. Свой шлюз (Worker или сервер) вписывается
как «Свой адрес».

## 8. Чего не хватает в конструкторе ClipGen

Передать владельцу `elementy.js`, обходится в `sborka.js`:

- воротник и конус со сквозным осевым отверстием;
- хвостовик без центрального стержня;
- глубина и шаг зубцов у `stem_fin`;
- пластина с выемками;
- прямоугольная разрезная стрела;
- бобышка на боковой грани;
- своя толщина каждому ярусу у `disc_stack`.

## 9. Как проверять правки

```bash
node --check js/файл.js          # синтаксис каждого изменённого модуля
```

Сквозная проверка в настоящем браузере — быстрее и честнее, чем глазами:
поднять статику и прогнать headless Chromium, загрузив синтетический снимок и
лист, затем прочитать `window.__S`. Что должно выполняться:

1. страница грузится без единой ошибки в консоли;
2. фото меряется, `S.izmer` не пуст;
3. лист режется на ожидаемое число панелей с верными ролями;
4. расхождение листа с фото ловится и лист отбрасывается;
5. «Убрать лист» чистит состояние.
