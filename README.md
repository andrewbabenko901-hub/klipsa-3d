# Разбор клипсы — 3D по фотографии

Веб-приложение: фотография пластиковой автомобильной клипсы и пара каталожных
размеров на входе — параметрическая 3D-модель, инженерный чертёж, STL и готовый
рецепт из элементов конструктора ClipGen на выходе.

Работает целиком в браузере. Сервера нет, ключ Gemini хранится только у тебя.

**Открыть:** https://andrewbabenko901-hub.github.io/klipsa-3d/

---

## Как это устроено

Три источника, и каждый делает ровно то, что умеет.

**1. Обмер силуэта — наш код, без всякого API.**
Фотография раскладывается на 40 полос по высоте, для каждой считается ширина
детали. Это даёт точные пропорции. Нейронка таких чисел дать не может в принципе.

**2. Разбор на примитивы — Gemini с жёсткой JSON-схемой.**
Даёт структуру: сколько тел, какие, в каком порядке, какое у каждого сечение.

**3. Сборка рецепта — снова наш код.**
Структура умножается на числа обмера и превращается в элементы конструктора
с размерами в миллиметрах.

Дальше из рецепта строится настоящая геометрия — та же, что в ClipGen, — и уже
из неё рисуются 3D-вид, четыре ортогональных вида и экспортируется STL.

## Почему схема ответа важнее промпта

Главное поле разбора — `sechenie`, с закрытым списком:

```
krugloe · krest_s_rebrami · srezannoe_ploskostyami · mnogogrannik
pryamougolnoe · oval · razreznoe · trubchatoe
```

По силуэту круглый конус, конус со срезанными плоскостями и конус с выступающими
рёбрами **неразличимы** — все три дают одинаковый профиль по полосам. Модель не
может ответить расплывчато: она обязана выбрать из списка и назвать число рёбер.
Ровно на этой разнице мы один раз ошиблись вручную, и именно её схема ловит сама.

В промпте есть отдельный кусок про то, как отличить выступающие рёбра от
срезанных плоскостей: у ребра узкая яркая полоса блика и поверхность по бокам
уходит внутрь, у среза грани плоские и широкие, а ребро — лишь линия стыка.

## Обмер: четыре ловушки, которые уже учтены

- Фон ищется **заливкой от рамки кадра**, а не по порогу яркости. Иначе белая
  деталь на белом фоне теряется целиком.
- Тонкие рамки, линейки и подписи отбрасываются по заполненности рамки. Без
  этого на кропе с чёрной рамкой обмеряется рамка, а не деталь.
- Ось выбирается **по асимметрии профиля**, а не по длинной стороне рамки. Иначе
  широкие плоские шляпки меряются поперёк детали и грибок становится катушкой.
- На снимках с двумя ракурсами берётся компонента с наименьшей заполненностью
  рамки — это одиночная деталь, а не плотный вид сверху.

Галочка «на фото есть красные пометки» дополнительно выкидывает ярко-красные
стрелки разметки.

## Что нужно ввести

| поле | зачем | обязательно |
|---|---|---|
| фото, 1–3 шт. | обмер и разбор | да |
| габарит Ø / ширина, мм | **самое широкое место детали** — задаёт масштаб | очень желательно |
| отверстие Ø, мм | ставится в элемент с отверстием | нет |
| длина штока, мм | подтягивает длину низа | нет |
| описание, подсказка | подмешиваются в промпт | нет |

Без габарита пропорции выйдут правильные, а масштаб будет принят 16 мм —
потом достаточно умножить.

## Ключ

Вводится в приложении (кнопка «Ключ и модели»), лежит в `localStorage` твоего
браузера и уходит только на серверы Google. В репозитории ключа нет и быть не
должно. Получить: [aistudio.google.com/apikey](https://aistudio.google.com/apikey).

## Деньги

Разбор одной детали — примерно 2500 токенов входа и 800 выхода, это порядка
**$0.003** на `gemini-3.5-flash-lite`. Лист картинкой — отдельная галочка,
примерно **$0.067** за штуку. Приложение считает расход за сеанс само и
показывает его под конвейером.

## Лист от нейронки и шаблон вёрстки

Галочка «рисовать лист разбора нейронкой» просит Gemini нарисовать лист:
слева четыре вида, справа разбор столбиком в профиль.

В репозитории лежит `shablon/shablon_verstki.png` — **чистый лист без единой
буквы**, он и грузится по умолчанию. Класть вместо него эталон с таблицей и
подписями нельзя: модель начинает копировать с шаблона текст, а иногда и саму
деталь, просто перекрасив её. Картинка сильнее текста, никакие запреты в промпте
это не перебивают.

Промпт картинки собирается **после** разбора: в него подставляется уже известное
число тел и их перечень словами. Поэтому лист получается согласованным с JSON,
а не сам по себе.

## Что можно править руками

Разбор — это предложение, а не приговор. В средней колонке каждый примитив
редактируется: тип, сечение, число рёбер и зубцов, доли высоты и ширины. Куски
двигаются вверх-вниз, удаляются и добавляются. Модель, чертёж и рецепт
пересчитываются сразу.

Внизу слева — четыре эталонные проверки. Они работают **без ключа и без сети**:
это заранее записанные разборы настоящих деталей, на них удобно смотреть, как
всё устроено, и проверять, что конструктор не сломался.

## Элементы конструктора

40 элементов, разложенных по трём зонам — ГОЛОВА, СЕРЕДИНА, ЛАПКА. Полный список
с параметрами — по кнопке «Справочник конструктора» в шапке.

Отдельно стоит `cone_ribs` — сужающийся нос с плоскими рёбрами. Сечение считается
как объединение круглого ядра и N прямоугольных рёбер:

```
ribk(θ) = min( R/cos(dθ), (t/2)/|sin(dθ)| )   при cos(dθ) > 0
r(θ)    = max( core·R, max по k из ribk(θ) )
```

**Булевых вычитаний нигде нет** — ни в одном из 40 элементов. Всё строится
сложением тел и прямым расчётом контура сечения. Это осознанное ограничение
ClipGen, и приложение его держит.

## Устройство файлов

```
index.html            разметка
css/stil.css          оформление
js/geom.js            помощники геометрии: цилиндр, коробка, тело вращения,
                      сектор, тело переменного сечения
js/elementy.js        40 элементов конструктора
js/obmer.js           обмер силуэта в браузере
js/gemini.js          обращения к API, схемы ответов, промпты
js/sborka.js          примитивы + обмер -> рецепт
js/vidy.js            инженерный чертёж и лист разбора
js/stl.js             экспорт STL
js/main.js            интерфейс и состояние
vendor/three/         three.js, положен рядом, а не с CDN
shablon/              чистый шаблон вёрстки листа
```

Сборки нет, транспиляции нет, зависимостей ставить не надо. Достаточно отдать
папку любым статическим сервером:

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000`. Через `file://` не заработает — ES-модули
требуют http.
